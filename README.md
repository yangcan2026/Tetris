# Tetris 俄罗斯方块

一款经典俄罗斯方块桌面单机游戏，内置「AI 自动托管」能力。项目提供两套同等实现，共享同一套游戏逻辑：

- **Python / pygame 版**（`tetris.py`）：侧重可读性与跨平台可移植性。
- **C++ / Win32 GDI 版**（`tetris.cpp`）：侧重 Windows 原生性能。

## 功能特性

- 标准俄罗斯方块规则：7 种标准方块（I、O、T、S、Z、J、L）、消行计分、等级与下落速度。
- 辅助视觉：影子预览、下一个方块预览。
- AI 自动托管模式：一键切换，由 AI 自动计算并执行最佳落点，可旁观演示。
- 兼容性辅助：暂停、重新开始、游戏结束结算。
- 界面全中文，双版本布局与坐标保持一致。

## 如何运行

### Python 版

依赖：`python3`、`pygame` 库（可选系统中文字体）。

```bash
python3 tetris.py
```

### C++ 版

依赖：Windows 平台、Win32 API 与 GDI；编译期要求 C++11+。

```bash
# 示例：使用 MSVC 或 MinGW 编译后运行
g++ -std=c++11 -municode tetris.cpp -o tetris.exe
```

## 操作方式

| 按键 | 行为 |
| --- | --- |
| ← / → | 向左 / 向右移动一格 |
| ↓ | 软降一格（+1 分） |
| ↑ | 顺时针旋转 90° |
| Space | 硬降落底并锁定 |
| P | 暂停 / 继续 |
| R | 重新开始 |

- **托管按钮**：点击侧边栏「托管 / 取消托管」按钮，切换 AI 自动游玩。
